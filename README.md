# My Project – Gaming Store Landing Page

## 📌 Overview
This project is a *gaming store landing page* along with a *single product page*, designed and developed using HTML and CSS based on a PSD file.  
The main goal of this project was to convert a graphic design (PSD) into a real, responsive user interface.

## 🎨 Technologies Used
- HTML5  
- CSS3  
- PSD to HTML conversion  
- Flexbox / Grid (if used)

## 🕹 Features
### ✅ Main Store Page
- Display of console game products  
- Header and navigation menu  
- Product section  
- Footer section  

### ✅ Single Product Page
- Full product description  
- Large product image  
- “Buy” or “More Info” button
